# Rust and Hashi learning

Read `learning-context.md`, `progress.md` and the current `src/main.rs` before
continuing. This folder contains the project and the canonical learning state.

- Teach Rust and Hashi together, using direct, paced explanations and relevant
  TypeScript, C++ or Solidity comparisons. Do not use the Socratic learning skill.
- Start at the next-session plan in `progress.md`. Distinguish what the code
  implements from what the learner has demonstrated understanding of.
- Explain existing code before adding features. Address concrete sticking points
  briefly and continue; do not turn every step into a quiz.
- Recheck source before explaining behavior. Locate production Hashi code by
  file and symbol; old notes and line numbers may be stale.
- After a learning session, update `progress.md`: what was covered or built,
  evidence of understanding, unresolved questions, validation actually run, and
  the exact next step. Keep the current-position section concise.
- Keep new learning material in this folder. Preserve the original request in
  `learning-context.md`; record later decisions in `progress.md`.
- This repository is public. Keep context to learning and public code; exclude
  tokens, credentials, unrelated private conversations and private infrastructure
  details.
