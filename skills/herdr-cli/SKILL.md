# Herdr TUI

Read `herdr --skill` and follow its current instructions before acting. For
configuration, also read `herdr --default-config` for the installed schema.

This is the legacy terminal multiplexer. `herdr-app --skill` covers the desktop
window, and `hc --skill` covers herdr-core terminals.

Keep this wrapper thin. Read upstream guidance from the installed binary on each
invocation rather than copying it here; upgrades then supply the current manual.
