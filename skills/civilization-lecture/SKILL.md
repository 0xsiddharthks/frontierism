# Civilization compatibility entrypoint

Read [the Predictive History skill](../predictive-history/SKILL.md) and follow its workflow. This entrypoint preserves existing references to `$civilization-lecture` and its helper paths; the shared implementation lives in `predictive-history`.

For an existing Civilization archive, preserve its source URLs, local ordinals, Notion page IDs, vault folder, and publication ledger. Its verified historical ordering is #1–#59 followed by #END at library ordinal 60. This is a Civilization snapshot, not a rule for other collections. The generic auditor accepts that legacy inventory without rewriting the library. New extraction commands require a private course profile; see [course profiles](references/courses.md).
