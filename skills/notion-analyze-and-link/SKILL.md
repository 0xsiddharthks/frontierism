# Analyze and link Notion notes

Make an existing collection easier to think with: identify relationships worth following, explain their significance, and add a small number of useful connections. This works with any Notion notes, including courses, podcasts, and research. It does not import new source material, export to Obsidian, or synchronize another copy. External research is a separate expansion when the task calls for it.

## Establish the collection

Fetch the requested hub and enumerate its selected pages completely, including database pagination. Inspect the existing schema, links, analysis sections, and learner-owned annotations. Use page IDs as identities; titles and lecture numbers are labels. A request concerning one course does not authorize scanning the whole workspace or adding cross-course connections. For a single source page, use the target collection specified by the user or its existing hub; resolve a genuinely ambiguous boundary before selecting targets.

Read [references/review-method.md](references/review-method.md) for the shared review method and private evidence record. Scan every included page for candidate relationships, then read the complete source and target pages for each proposed connection. An inaccessible or truncated page cannot support a verified edge.

## Analyze, then publish a focused change

Prefer a concise Connections section with a native Notion page mention and a sentence explaining why to follow it. Reuse an existing equivalent section. Add inline concept links only where they help reading, preserve the original visible wording, and use native linked rich text or page mentions according to connector support. Do not simulate Obsidian `[[...]]` syntax in Notion. A Notion relation property is useful only when the existing schema or requested browsing experience calls for one; it is not required for ordinary connections.

For a requested synthesis, explain common mechanisms, contrasts, assumptions, and unresolved questions in the hub or a clearly named analysis page within it. Link supporting pages beside each comparison. Distinguish the notes' claims, independently verified evidence, and your interpretation. Do not treat repetition across pages as corroboration or silently turn conjecture into fact. A simple linking request does not need a new report or extra page per concept.

Prepare exact source/target IDs, evidence, placement, wording, and before/after content privately. Reconcile with existing connections so reruns improve or skip them rather than append duplicates. When parallel review is authorized, assign disjoint source pages, let reviewers read the full target collection, and have one coordinator apply reviewed changes.

Before writing, fetch the page again and compare the edited region with the reviewed snapshot. Apply only the intended analysis/link changes; retain comments, user notes, progress, existing media, source citations, headings, and font. If concurrent edits invalidate the patch, rebase it onto the fresh page or retain the specific conflict without overwriting it. Do not rewrite the whole lecture from a stale draft.

## Verify

Fetch every changed page completely. Check the proposed native targets, preserved visible wording, section placement, existing user content, and absence of duplicate destinations or accidentally lost blocks. Open representative links and inspect the rendered section. If a write result is ambiguous, read the actual page before retrying; reconcile the intended change rather than appending it again.

If a private publisher ledger exists, update its current content/readback record to the verified page while retaining the pre-analysis snapshot and review evidence. Otherwise a future publication audit could mistake the approved analysis for drift or overwrite it. Never mark unreviewed source claims verified just because links resolve.

Report the pages reviewed and changed, meaningful connections added or revised, synthesis produced when requested, and unresolved gaps. Existing Obsidian copies are unchanged until a separate export or local analysis is requested.
