# Per-source draft handoff

Use this contract only for delegated or sequential draft-only collection work. A direct single-source publication need not produce a separate handoff file.

The coordinator supplies:

- Stable source key, exact source URL/file identity, edition/version and requested scope; ordinal when meaningful.
- Learning goal, analytical focus, relevant context/dependencies, and any phase barriers.
- Acquired snapshot and hash/locator basis, or bounded acquisition instructions when acquisition is delegated.
- A private output location and requested metadata vocabulary/schema. A source assignment is not permission to choose a Notion destination or publish.

The analyzer reads the shared source-to-notion skill and its relevant references. It returns a readable analytical Markdown draft plus a concise private structured record containing:

- The assigned source key, edition/scope, actual source URL, acquisition provenance, snapshot/content hash, and locator basis. Identify an actual source/version change rather than silently analyzing another release.
- Actual ranges read, consequential footnote/visual inspection, missing material, attribution uncertainty, and the resulting coverage status.
- Draft path and proposed source metadata/tags in the coordinator's vocabulary; leave unknown values empty.
- Consequential source locations and unresolved questions. Candidate connections use other manifest source keys with reasons and remain unverified until cross-source review.
- Completion state: **ready** for a reviewed full-scope draft, **partial** for identified missing scope, or **needs_source** when only metadata is available. None of these states is a Notion QA value or a learner-progress update.

The draft itself explains the core question and necessary concepts from first principles, reconstructs the reasoning or mechanism, examines evidence and qualifications, identifies the crux and serious objection/limitation, and locates consequential attributed claims. Adapt structure to the source; no duplicate analytical template lives here.

Use the collection's existing compatible record format when one exists. The coordinator checks identity/hash/scope, actual coverage records, substantive quality, and proposed metadata before accepting a result. A complete record is not proof that the material was read or the interpretation sound. Retain feedback and revisions by source key; one owner resolves each source's outstanding issues before publication.
